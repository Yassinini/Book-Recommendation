# Book finding system
### This project is a simple find your book, using a dataset from kaggle that includes some bestsellers, we use them to code in some search methods you may use to find your books
--- 
## How this works?
### When running the program, you are met with a fully cli program that gives you numerical options. choosing an option takes u to the next step with a map of whats next from each option. <br>
### An option map will be made in V2
